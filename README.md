# ThreadHelm

ThreadHelm is a planned Windows-first, local-first desktop application for directing multiple
terminal-based AI agents from one calm workspace.

The project takes inspiration from the functional core of Munder Difflin: real local agent
processes, coordination, messaging, memory, terminal access, and centralized user control. It does
not adopt the animated office, character, pixel-art, or game-like presentation.

## Project status

ThreadHelm is in its governance and product-definition stage. Application architecture, provider
support, and UI flows will be defined through feature specifications before implementation.

The project constitution is the current source of truth for product and engineering decisions:
[`.specify/memory/constitution.md`](.specify/memory/constitution.md).

## Product direction

- Windows-first and local-first
- Useful orchestration over visual theater
- Lightweight, adaptable, accessible desktop UI
- Explicit control over agent processes and workspace access
- Observable, testable, and recoverable work

## Development workflow

This repository uses Spec Kit. Proposed features begin with a specification and are checked against
the constitution before implementation.

Contributions and security reports are welcome. Read [CONTRIBUTING.md](CONTRIBUTING.md) and
[SECURITY.md](SECURITY.md) before opening an issue or pull request.
