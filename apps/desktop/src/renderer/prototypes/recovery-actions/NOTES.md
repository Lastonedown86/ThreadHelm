# Recovery and destructive-action design gate

- A is a dedicated recovery page.
- B keeps recovery evidence inside the affected mission.
- C provides a cross-mission attention queue with an exact-target detail and Recovery Coach.

**Selected: C — Attention queue, with B as the opened mission treatment.** Unknown outcomes are
never replayed or classified automatically. A replacement is new work and requires review. Content
deletion names the exact mission, removed content, linked memory, retained receipts, exclusions, and
blocking unknown work before confirmation.
