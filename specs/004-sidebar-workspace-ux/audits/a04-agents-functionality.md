## Proposed interaction design

Recommended next bounded slice: AGT-001 + AGT-002, roster access and selection. Agents -> roster -> All/Active/Disabled -> named row -> exact detail. Keep a bounded Load more action and explicit filtered-empty state. Paging retains selected ID; filter exclusion closes detail; loading cannot present an unmarked previous target. Reuse current explicit import confirmation and revision-bound eligibility changes. Propose shared reflow work separately under AGT-003/A01 after its own viewport/focus acceptance cases.

## Section acceptance summary

- Visual/interaction: observed failures in filter/detail coherence and scaled layout; baseline screenshots inspected. Existing sampled keyboard flows pass, not complete accessibility acceptance.
- Logic: profile paging drops a real cursor; exact-target enable/disable and manifest boundaries hold in sampled paths. Delayed selection and in-flight draft edits remain source-only/pending.
- Functionality: UI-created profile fields and disabled state independently read back and restored after actual isolated restart; no process launched. Export safety verified in selected Windows integration tests.
- Missing: malformed/cancelled/expired import UI, delayed/error/stale loads and saves, rapid repeated confirmation/Escape, full wizard 200%/narrow/keyboard matrix, 51-profile restart UI count, disabled-source transitions and complete mission binding round trips. Feature 002 owns provider/authority capability; these observations do not close its gates.
