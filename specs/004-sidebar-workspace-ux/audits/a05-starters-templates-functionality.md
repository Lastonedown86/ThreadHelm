## Proposed interaction design

Agents -> named Saved drafts / Generic starters / Local templates. Resume opens the named draft at its saved stage; Escape and Save draft and close preserve latest acknowledged fields. A local template's Delete flow first identifies any dependent drafts and provides a route to them; eligible deletion reviews the exact template/revision, confirms once, and removes it. Failed/expired review offers a valid next action and keeps content intact. Local copies and imported profiles stay distinct from generic bundled starters and from live sessions.

## Section acceptance summary

- Visual/interaction: draft identity and failed-delete recovery need improvement; standard error dialog and shared scaled layout inspected. Six generic starters stay separate from local/test fixtures in sampled UI.
- Logic: copied revisions and draft provenance are explicit; 20-open-draft limit is real and non-mutating on denial; delete dependency guard is correct. The current failed-delete receipt recovery is inconsistent with its message.
- Runtime functionality: actual UI copy, draft Escape-save, blocked delete, repeated confirmation and restart exercised, with authoritative main data readback and no processes launched. Existing tests cover successful template revision, enable/disable, duplicate and deletion.
- Missing: >20-template paging UI, paging refresh, duplicate key and invalid template name UI, disabled/stale source round trips, delayed save races/storage failures, all dialog narrow/scale/focus variants, pending-action Escape and expiry durations. These remain pending; no coverage-complete or Feature 002/004 completion claim.
