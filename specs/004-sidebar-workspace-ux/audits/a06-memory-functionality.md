## Findings and proposed interaction design

All findings below are **proposed**, dated 2026-09-05, and **not implemented**. Feature 004 owns presentation/state coordination; Feature 002 remains owner of memory authority and durable lifecycle. Preserve main-owned exact tokens, scope checks, citations and deletion boundaries.

Recommended first implementation slice: **MEM-001 only**, a bounded exact-review correction. Then address MEM-003 scope ownership and MEM-004 pagination. MEM-002 requires an explicit reading-list lifetime/association decision before extending persistence. Use common section conventions for stable selection, truthful lifecycle badges and in-place recovery. Modal failures should be reachable inside the active dialog; delayed/error focus behavior remains to be measured before declaring compliance. Keep publication separate from search and retain deliberate durable confirmation.

## Section acceptance summary

- Visual/interaction: observed failures in reviewed editing, scope continuity, reading-list status and paging detail. Standard-size screenshots inspected; complete keyboard, accessibility and reflow acceptance pending.
- Logic: main snapshot and lifecycle rules work in sampled cases; renderer invalidation/remount/snapshot/paging logic causes four reproducible inconsistencies. Out-of-order search/detail responses and revoked workspace selection are source concerns requiring controlled runtime probes, not additional confirmed findings.
- Functionality: exact initial publication, revision creation, retraction, deletion and restart readback observed independently. Existing tests add conflict resolution, expiry, scope isolation and atomic deletion evidence. No live provider sessions were created. A stale reading-list snapshot is not a failed durable purge.
- Remaining scenarios: narrow/200% text, complete Tab/Escape/focus return, all cancel paths, UI operation failure/retry/expiry, interrupted writes, rapid cross-scope reads and persisted mission association expectations. Add focused probes after design decisions; do not label this matrix fully verified.
- Cross-section: paging and identity consistency echo Agents; scope continuity echoes Sessions. A07 Attention is the next unaudited section; A08/A09 and earlier open findings remain pending.
